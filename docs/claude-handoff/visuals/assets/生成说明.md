# 食物识别图谱 v1

生成方式：内置imagegen工具，参考用户提供的餐牌外观生成；不是菜品实拍。文件为`food-atlas-v1.png`。原用户餐牌保存在上级references目录，没有修改原文件。

用途：静态UI评审中的餐品识别图，CSS按3×3网格展示单格。默认菜品照片不代表精确云吞/肉片数，也不能代替实际售卖照片审核。Kosong生产态需要独立熟净面图，当前图谱没有该资产；预览用图解训练卡说明肉类移除，不声称资产清单已齐全。
